# App Changelog - 2026-08

## 2026-08-24 17:16 CT - Fixed-language routes, accessible draft primitives, and CSS readiness

- Added the optional fixed-language route contract across shared types, schemas, runtime validation, local preview, client navigation, SSR, sitemap, canonical, and hreflang output. The hub accepts the same normalized restricted BCP 47 variant subtags as Authoring and Runtime Read. A route-bound language is transient and does not overwrite the saved preference used by ordinary routes.
- Added the generic authoring primitives needed by the Astra Legal calculator and campaign: radio semantics and keyboard behavior, nullable number inputs, localized validation associations, focus-by-id instructions, live result regions, exact currency formatting, safe hash navigation, and per-link language-query preservation control.
- Coalesced CSS-readiness work by normalized class, combo, and theme signature; obsolete cycles are canceled before additional CSSOM work and synchronous failures release the signature for a safe retry.
- Preserved the authored distinction between an explicitly empty decorative image `alt` and an omitted `alt` in `generic-media`; document-style media continues to fall back to its source URL when no non-empty label is available.
- Centralized server-rendered not-found copy so Chinese requests receive aligned Chinese title, metadata, message, and home action instead of the previous Spanish fallback. A fixed-language `/404` now carries the final runtime route language through the SSR document, head, and diagnostic shell while ordinary unbound not-found routes keep their request language.
- Synchronized the canonical and draft-template Commerce schemas, golden fixture, and canonical/template readiness validation with the Config Authoring contract: required plan-change and pause policies, optional tax and bounded migration policies, the code-owned migration capability, tracked-inventory enforcement, and the optional shipping-country allowlist. Both schema copies match the Config Authoring source after LF normalization (9,978 bytes; SHA-256 `1F1B2934FBBF025ABC3C1CB7D70FAF2EAB4D856DFC7CCA6461E53037A4E3B6CE`).
- Added focused Angular, schema, local-preview, navigation, CSS-readiness, SEO, sitemap, and production SSR regression coverage. Final local checks passed 841 Angular cases, 33 schema cases, two focused SSR parity cases, and 11 local-context cases; the broader SSR smoke passed 23 of 27, with the same four unrelated failures reproduced at the base revision. Local implementation and QA did not deploy, publish, promote a branch, or mutate cloud state.
